# 笔记生成、排版与表达

编写课/章/课程笔记前读。本模块加工原反馈，不让学生额外输入。原反馈缺少实质内容时返回缺项；没有实际错误或作答就不创建个人错因。

## 从反馈到可独立阅读的笔记

先确认所属章节、本次已讲边界及完成信号，从原记录提取重要概念、模型假设、关键推导、符号/单位、已展示示范和考试表达依据，保留稳定主题ID与来源定位。这份清单先于正文存在，随后形成v3 coverage，不用成品标题替代输入覆盖检查。章节只讲了一部分就清楚标注已讲范围；“完整”指范围内实质内容齐全，不靠凑篇幅或节数。

章节是主要阅读单元。先辨认本章要解决的问题、依赖的概念/关系及所得结论，按这种依赖组织，而不是按聊天日期逐课拼接。让概念引出关系、关系引出推导、推导回到物理/学科意义；同一主题在多课反复出现时合成一处解释，保留各次新增的条件、例子和有价值的疑问，在连接处说明“前面的结论为什么还不够，接下来要解决什么”。来源定位仍可回到各课，不把实际教学顺序伪装成唯一推理顺序。不要复制聊天问答、重复开场白或把所有句子都拆成项目符号。首段交代问题与知识联系，正文用连贯段落，步骤/比较/条件才用列表或表格。一次课的示范和定义不能因看起来不像“重点”便一概删掉。

取舍依据是该内容在解释中的作用：回答主问题、让关键变换成立、区分易混情况、展示方法如何落地的内容留正文；不影响主线的延伸、第二种补充证明或较长旁注可折叠；寒暄、原地重复和无知识增量的操作过程可删。原反馈把两种条件下的结论分开时，不能为去重合成无条件规则。例子可以缩短重复计算，但保留选择方法的线索与结果意义；有矛盾或缺失时标明待核对并交回维护者，不靠猜测补齐。

默认完整视图直接呈现核心解释、必要中间式、符号条件、核心证明、原反馈已有的示范及边界，不要求逐卡展开。只有延伸推导、较长旁注等补充才折叠；移除折叠内容后主线仍须自足。每个公式在附近说明它描述什么、符号含义和成立条件；重要公式与对应解释/图示放近。符号沿用课程约定，同名符号含义变化时明确说明。

必要图像与对应解释一起保留，按[教学图像规则](../../course-study/references/teaching-visuals.md)复用教师已核验的图及其来源/参数；核心图直接可见，不能为精简版面删掉解释空间、变化或条件比较所需的关系。重绘或裁切后核对受影响的关系与实际显示；缺图、依据不足或概念不清交回教师，不另起教学内容或图像登记库。

最后回到原反馈逐项核对。标出已整理位置、合并位置和未展开原因，确认关键假设、积分常数/初始条件、正负号、单位、结论与例子的作用没有丢失。脚本只查映射结构和版本，不能代替这一学科核对。

课程结束后另作跨章整理：从全课程的主问题、共同方法和重要条件重新建立顺序，联系实际学习中反复出现的疑点与有效解释。可引用章笔记定位，但正文不能只是章链接目录或文件拼接。完成范围由规划确认，不补造未学章节或个人掌握结论。

## 推导的关键桥梁

先说明要找什么、为什么选这个起点。在正文中突出会影响方法选择或理解的桥梁：本步操作、为什么这样做、成立条件，以及实际用到的先修概念。普通代数连续展开，不每一行都套相同模板。记忆线索可在精简视图提炼为“目标→起点→关键选择→结论与条件”，完整推理留在直接可见的正文中。

先修解释短且原反馈充分时放在本步附近；解释较长时在同页保留适当小节并链接。大范围基础缺口交教师与规划，笔记标待补，不能自动另开课程或替代补课。边界/反例在确有教学价值且有依据时使用，避免把必要条件写成无条件规则。个性化落在原记录确实出现的问题上：在对应推理处补清那个连接，不重复张贴“你容易忘”等标签。只看懂解释、接受提示或省略常规代数均不自动等于掌握或基础薄弱；正确的关键式加明确代入可以是有效简写，不把它改写成个人错误。

已展示例子采用适量的“选择理由→关键处理→结果意义/检查”，让读者知道为什么选这种方法。复用原示范，未展示的正式练习解析不因编写笔记而公开；不新增正式练习或第二套评分。

## 概念、术语与考试表达

概念/术语在首次需要它的正文处解释：中文理解、英文术语和精确定义；再按内容补条件、符号/单位及易混概念。英文段落可用lang="en"标记语言，便于辅助阅读。日常直觉与正式定义分清；缩写首次出现说明全称，保留有用别名供检索。不要把所有概念单独抽成卡片后让正文失去连贯性，也不填空白栏目或机械编造。

state给足简明陈述，define说明定义所需的对象和限定，explain补上题意要求的理由/因果关系。必要英文参考表达紧邻已讲清的概念，不再另建一个重复定义的state大单元。合理等价表述可以成立，不把一套关键词计数当评分规则；官方表述、真题出现与自拟参考表达继续按原考试依据区分。

同一概念已讲清时，其他小节只补当前用途与差别，用related链接，避免反复抄同一定义。定义不能脱离条件。采用能区分论证地位的动词：“定义为”引入约定，“假设/在该模型中”标条件，“恒等地”需确为恒等式，“由……可得”指出推论，“实验表明”须有观察依据；不能把模型假设说成由代数证明的事实，也不把一个例子说成一般证明。限定词贴近对应结论；例如来源讲的是作用量驻值，就写stationary，不能顺手简化成一定取minimum。此例仅说明表达精度，实际按课程来源判断。

术语与符号速查从已讲清的正文提取：中文、英文、简明含义及必要的符号/单位/条件，链接到原解释。同符号在不同模型中含义或单位不同，应按上下文分条，不把广义量一律套笛卡尔量的单位。重要公式编号用于反复引用、比较或方法起点；引用处仍说明为何用它，而非只写“由式……可得”。更改定义或公式时，同时核对精简视图与速查，防止出现两套说法。

## 可选回忆与阅读层级

完整、精简、回忆三个视图各有用途。完整视图连续阅读。精简视图按本节实际内容压缩成可重新展开的推理线索：要回答什么，从哪条定义/关系开始，为何选这个操作，关键条件是什么，得到什么及如何使用；有价值的对比也保留判别条件。不要求每节都有这六个栏目，不逐行重复正文，不只摘最终公式或把标题改成项目符号。它不能承载正文缺失的内容。

压缩示例（仅说明写法，假定原反馈已经讲清此模型，成品公式仍用MathML）：

- 信息不足：“直接积分得到指数衰减，记住最后的公式。”
- 保留推理线索：“在衰减率λ为正常数、N为正的模型中，从dN/dt = −λN出发。右侧与当前数量成正比，因而分离变量后积分；用N(0) = N₀确定积分常数，得到N(t) = N₀e⁻λᵗ。它用于该模型的数量预测；若λ随时间改变，不能直接沿用常数λ的结果。”

示例没有替代正文的积分过程，也没有给所有学科规定同一种模板。回忆视图先给中性的recall问题，必要时针对“为什么用这个起点”“条件变化后哪一步不再成立”“这个例子如何体现一般关系”提问；只覆盖原反馈已有解释。hints按“起点线索→关键选择”递进，答案按需展开并可回到正文。不在任务标题中先写出答案，不强迫所有词汇做填空，也不凭展开/点击判定表现。

电脑阅读优先，沿用已认可的克制版面：适中行宽、清楚的章节层级、可定位的目录与安静的来源说明。标题只保留章、主题和必要层级，不用过多徽章/卡片包装同一段推理。使用现有本地字体，重点靠位置和内容组织，不把大段文字都加粗。必要图片使用figure/figcaption与具体alt，靠近首次解释处；图像和样式内嵌，公式用原生MathML。手机是可选辅助，不为手机减少内容或收起核心证明。

生成后在桌面和缩放下查看真实内容，测试完整正文、视图切换、键盘、检索空结果、回忆提示/答案、相关链接和离线操作；不将手机验收设为必需。打印恢复全部主题、完整正文与补充，不受当前搜索筛选或回忆模式影响；返回网页后恢复原状态。PDF保留清楚的公式、分页和批注空间，不覆盖既有批注文件。

## 交付前的内容核对

这是模块内部回读来源的检查，不给学生加表格或评分。按当前章节实际内容检查，缺项要修正文或返回维护者，不能靠新增标题使检查通过：

| 核对点 | 可直接发现的问题 |
| --- | --- |
| 章节能否独立读通 | 是否只有课次摘录，前后结论为何相连、这一步解决什么是否说清。 |
| 取舍是否忠于已讲范围 | 源清单中的重要概念、条件、证明和已展示例子是否有位置；被合并的内容是否仍保有不同前提。 |
| 论证是否成立 | 起点、关键桥梁、符号/单位、边界/初始条件是否与原反馈一致；定义、模型与推论是否混淆。 |
| 图像是否承担解释且准确 | 需要看见的关键关系是否已有图；图的曲线/箭头/约束、条件和图注是否与正文及来源一致，是否实际查看成品；具体核对沿用教学图像规则。 |
| 精简后能否恢复主线 | 是否只剩答案；删掉的理由是否恰好是选择方法所需线索；适用条件与正文是否一致。 |
| 个性化是否有记录依据 | 疑点是否确实出现；是否把有效简写、提示后的表现或未作答题目误写成错误或掌握。 |
| 速查与引用是否可信 | 术语、符号和重要公式是否回到正确正文，条件是否一致，编号是否指向实际关系。 |

通过只说明这些内容已核对，不证明学生已记住，也不证明笔记产生某种学习效果。学科正确性仍需实际回读，结构校验和界面测试各自报告。

## 设计依据

采用的是具体编排思路，不把外部项目的效果宣称移植为本模块验证：

- [Cornell官方笔记指南](https://lsc.cornell.edu/wp-content/uploads/2015/10/Cornell-Note_Taking-System.pdf)：摘要、线索问题，以及围绕意义、原理、应用和已有知识联系的反思；不照搬纸张分栏，也不接管复习时间安排。
- [IES学习组织指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：解释性问题、图文对应和抽象/具体表征联系；这里据此保留推理理由与示范的作用，不在笔记模块增开教学或练习流程。
- [Open Notebook](https://github.com/lfnovo/open-notebook/blob/main/docs/3-USER-GUIDE/working-with-notes.md)：来源加工、顶部摘要和去除聊天填充语。
- [Tufte CSS](https://edwardtufte.github.io/tufte-css/)：连续阅读、克制层级、解释/图像靠近对应正文；不加载其字体或外部CSS。
- [Sphinx Proof](https://sphinx-proof.readthedocs.io/en/latest/syntax.html)：定义、条件、证明和稳定引用分清；这里使用轻量本地结构，不引入Sphinx运行时。
- [OpenStax示例编排](https://openstax.org/books/university-physics-volume-3/pages/6-2-photoelectric-effect)：选择理由、处理、结果意义；仅采用组织方式，不复制教材题目和正文。
- [Revision Tutor](https://raw.githubusercontent.com/yangcodingmaster/Revision-Tutor/main/SKILL.en.md)与[Cloze](https://github.com/DearVikki/obsidian-cloze-plugin)：关键跳步、遮答及分级提示。
- [Quartz](https://quartz.jzhao.xyz/features/backlinks)：概念链接与查找；本文档仍为自足离线文件。
