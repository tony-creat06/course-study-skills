# 学习笔记

接收其他四模块已有反馈，随学习积累按章组织、可连续阅读的个性化lecture notes。中文讲清知识联系，保留英文术语及必要的英文答题表述。不要求学生填写输入表、重新提供材料或接受笔记采访；内部数据由模块准备。

## 接收与边界

自动整理仅用于已建立的持续系统课程及其实际保存反馈；零散讲解、实验任务和报告不自动进入本组。明确点名本模块仍按指定范围整理，不启动全部模块。先读[共同记录约定](../study-planner/references/coordination.md)和[反馈交接](references/handoff.md)。沿用规划确认的学习者、课程根目录、已讲范围和课/章结束信号；不能根据工作目录自行选课程。原模块给出的同一记录快照可复用，最终保存仍验证来源版本。

不必每次让四模块全部执行；无新考试/题目反馈时复用有效记录，无相关内容则省略该栏目。身份/根目录缺失时向当前主流程返回缺项、保留原断点，不自建课程或伪造来源。直接调用从已确认的课程上下文接收同样反馈。

仅用notes角色写notes/阅读产物；不修改计划、检查点、课堂、考试、题目或作答记录。发现错误返回原维护者，更正原记录后重建。基础缺口交给教师与规划，笔记保留局部必要解释或待补位置。回忆提示不建立掌握状态，也不代替正式练习。临时答疑由规划采用后纳入对应课程笔记。

## 按章积累与课程整理

主流程保存一课反馈后，将新内容合入所属章节的同一份笔记。每章是主要阅读单元；课级临时笔记按需要保留，不要求先生成一套课笔记再汇总。章节尚未讲完时明确标注实际已讲边界，保留完整的已讲正文；只有规划确认章结束后才称本章完整。没有实际运行就没有后台生成、同步或唤醒。

围绕本章的问题与知识联系编排，覆盖范围内的重要概念、模型、术语、核心推导、已展示例子和必要结论。不能只剩几段推导和state条目，也不靠篇幅、栏目数量证明完整。概念、理由、计算与结果意义组成连续正文，数学公式附近说明符号和成立条件。按[教学图像规则](../course-study/references/teaching-visuals.md)复用已核验的必要图并放入对应核心解释；缺少关键图或依据不清时交回教师，不让笔记只剩公式，也不补造未学内容。必要的state / define / explain参考表达放在相应概念旁，无考试依据不称必考，自拟表达与官方表述分清。

默认打开就能读完整核心正文：定义、必要先修、关键理由、中间式和核心证明都直接可见。折叠只用于补充推导、延伸或较长旁注；缺少它就读不懂主线的内容必须移回正文。推导说明从哪里开始、为何选这个起点、关键变换为何成立，以及结论何时适用；普通代数自然衔接，不把每行都套固定栏目。按内容选结构，不强迫每个术语重复整套模板。

生成前读取[笔记生成与表达](references/note-writing.md)：先从原反馈列重要主题与来源，再按知识依赖合章、取舍、编写和逐项核验。压缩聊天重复，不压掉让结论成立的假设、关键理由和已讲示范；精简视图保留问题、起点、方法选择、条件及结论用途，避免只罗列结果。新笔记使用v3章节结构与覆盖映射，说明每个重点整理/合并到哪里或为何未展开；不从成品反推一张永远全通过的清单。覆盖是内容定位，不是学习进度或掌握状态。

网页提供完整、精简、回忆三个视图。完整视图是独立成立的lecture note；精简视图提取复习路线和关键条件；回忆视图按需给起点、方法选择等提示和答案，并可回到对应正文。后两者不代替完整正文，也不要求每节都配回忆任务。回忆不另出正式题，不把点击记作作答或掌握。题目模块未展示的解析不进入笔记；已展示示范可整理，实际作答/提示事实仍留原记录。

整门课程完成后，依据规划确认的完成范围及实际学习反馈，另外整理全课程笔记：重新梳理章节之间的联系、共同方法、条件差别及有依据的易混点，不简单拼接章文件，也不提前补写未学章节。

按需建立中英文术语/符号速查与关键公式编号，便于从推导回查含义、条件和原位置；只选有反复查阅价值的内容，不把每个中间式都编号。速查和引用补充正文，不能替代首次解释。复用稳定主题ID建立同页相关概念、先修链接和术语定位；若相关解释是读懂本页所必需，正文应自足，不能只把读者送去另一文件。网页内嵌正文检索，可按中英文名称、别名和内容查找；不依赖服务或另建知识库。

## 交付与更新

按[离线网页与PDF](references/offline-notes.md)准备内部数据并渲染。默认单文件HTML，完整核心正文、目录、三个视图、正常数学排版及资源都在文件内，断网仍可阅读与检索。电脑阅读是主要设计和验收目标，手机适配为可选辅助，不为手机压缩正文或改变桌面主布局。LaTeX源码不作为学生看到的数学正文。旧v1/v2继续可渲染，不批量迁移旧课程。

沿用稳定课/章ID更新同一笔记；反馈变更先回读核对，合并用户手改，不强制覆盖。保存同时检查反馈SHA和目标旧SHA。生成失败将待整理范围交回规划，保留课堂完成事实与接续点。

按表达指南的内容核对准则回读原反馈，核对章主线、压缩前后条件、符号、推理和来源；图像按共享规则核对其声称的关系、图文一致性及实际画面，改图后重查。实际查看桌面正文、视图切换、补充折叠、检索、速查/公式引用和离线效果；结构检查不证明数学正确或学习效果。手机不是必验门槛。需要PDF时输出完整内容并检查分页/公式，未成功导出不称已交付PDF。

返回笔记路径、已整理范围、反馈版本、缺项/疑点及实际验证范围；由规划按[课程文件入口](../study-planner/references/course-files.md)刷新学生可见的笔记入口和原检查点中的产物索引，不另建计划或把读过笔记记为掌握。
