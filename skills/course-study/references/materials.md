# 材料接收与用途分类

仅在新建课程、收到新资料或核对材料冲突时读取。

## 先登记，再按内容判断

清点指定目录内全部文件，包括子目录；保留原路径和版本，不移动或改写原件。先做轻量清点与可读性检查；当前主线读目录/相关段落，其余资料按使用需要抽样分类，未读的明确保留。无需在首讲前逐份通读或比对全部版本。文件名只用于定位。对当前要讲的部分细读并查看相关图示；扫描、手写和批注以原页面核对，不能把空文本层当成空白内容。

在课程 `materials.md` 中记录每份文件：标识与路径、内容确认的版本/日期、用途及范围、实际检查位置、可读性、重叠/冲突/待确认项。用途可多选、细化到页/章节：

| 用途 | 用于什么 | 边界 |
| --- | --- | --- |
| 大纲/教学与考核要求 | 范围、学习目标、先修、形式 | 旧学年要求不能直接当成现行要求 |
| 讲义、slides、课程笔记 | 教学主线、概念、推导、例子 | 先核验章节覆盖与内容，含答案时另标 |
| 手写与批注 | 板书推导、补充解释、可能的纠正 | 确认可读页及作者/版本；不自动优先于正文 |
| 习题/题卷 | 练习、应用深度、考核表现 | 真题覆盖不等于全部课程范围 |
| 答案/评分说明 | 解法核对、反馈、评分依据 | 不当作教学大纲，不假定无误或完整 |
| revision/公式表 | 复习重点、压缩线索、遗漏核对 | 不用压缩稿替代从零讲解 |
| 教材/推荐书目 | 解释、补先修、替代例子 | 书名不代表读过正文；无需上传整本才能开课 |

例如：题目与答案同册应同时标注两种用途；带 errata 的试卷保留更正页；名称像试卷的 PDF 可能实际是大纲。题卷封面年份、适用学年、文件名年份可能不同，分别记录。

## 主线、重叠与冲突

优先使用内容确认后适合本门课的主线资料。没有完整主线时从可读资料组合路线，说明依据与缺口。已有路线不是不可变脚本。

同一节的完整稿、分卷、手写、不同年份版本可能重叠，不能按文件数量重复教授。通过章节和内容对应确定关系；仅名称相近时记录“可能重叠，待比对”。版本日期有矛盾时保留两个证据，不默默选一个。

发现公式/答案冲突或原页不可读时，按[材料疑点与读取能力](source-checks.md)核对原意、复算及证据边界；未确认疑点不能记成已确认缺陷。影响当前结论且尚不能解决时限定该部分；其余可确认内容继续。

## 检查范围必须诚实

可用自然语言或简单标签区分：仅登记、内容抽样、相关段落已读、相关页面已视觉核对、待核对。给出具体页/章节；“抽取了全文”只能说明文本处理范围。

建立整个课程的粗路线，当前课保留更细的内容覆盖与例题位置。新资料到来只更新受影响条目、路线与笔记；保留更正理由。不要把预处理所有资料变成开讲前的长时间门槛。
