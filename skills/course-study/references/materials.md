# 材料接收、实体分类与章节索引

已确认进入整套课程学习后，首次接收、后续补充或接续课程时使用。目录、工具命令与兼容旧课程规则以[课程文件入口](../../study-planner/references/course-files.md)为准；本页负责按内容判断用途和实际读取范围。

## 一个新增入口，同一套接收流程

向用户给出本门课的实际路径：`<项目>/inputs/course-materials/<课程ID>/inbox/`。以后可直接把新增讲义、字幕或其他资料放进去，也可明确提供外部文件位置。文件放入后不会在后台自行处理；下次课程接续时先检查接收情况，用户也可说“处理新增资料”立即接收。

首次清点和以后接续都扫描已登记来源目录及本课 `inbox/`，覆盖子目录，核对新增、改动、缺失、移动和同内容副本。扫描的哈希和文件信息只证明文件变化，不能证明读过内容。先查看变化报告，再决定当前学习所需的内容核对；不能直接沿用旧分析后才检查新文件，也不能把未经确认的缺失当成资料已被删除。

初次接收与增量接收使用同一流程：清点 → 检查内容/可读性 → 确认分类与章节 → 按工具规则归档并登记 → 核对影响 → 告知结果。先读目录与当前主题相关段落，其余资料可按需要抽样分类；无需在首讲前逐份通读或比对全部版本。扫描、手写和批注以原页面核对，不能把空文本层当成空白内容。

## 实体按用途，章节用索引关联

每份资料只保留一份规范归档副本，位于本课原始资料根目录下：

| 目录 | 内容与判断边界 |
| --- | --- |
| `inbox/` | 待接收的新文件；不是已确认分类 |
| `syllabus/` | 大纲、教学/考核要求；分别记录适用学年，旧要求不能直接当成现行要求 |
| `lectures/` | 讲义、slides、板书、教师课程笔记及手写批注；核验实际覆盖，含答案时另标用途 |
| `transcripts/` | 教师上课的原始字幕/转写；按[字幕读取规则](transcripts.md)结合上下文使用 |
| `exercises/` | 习题册、练习卷、作业题；题目与答案同册时只存一份并标多用途 |
| `solutions/` | 独立答案、解题说明与评分参考；不假定无误或完整 |
| `exams/` | 真题、mock、同册答案和 errata；独立评分说明归solutions并关联题卷；用索引关联题卷与答案，不按题频代替全课范围 |
| `revision/` | 复习提纲、公式表；不用压缩稿替代从零讲解 |
| `textbooks/` | 已提供的教材/书籍；推荐书目条目不等于读过正文，也不必上传整本才能开课 |
| `supplements/` | 已确认用途的其他补充资料，如额外阅读与说明 |
| `unclassified/` | 内容暂无法识别或分类把握不足的文件；保留待核对原因 |

分类以实际内容和用户明确说明为依据；文件名、扩展名仅作查找线索。不能把所有 PDF 当讲义、所有文本当字幕，或把难判断的文件一律塞进补充资料。低把握文件先待分类，不因此从清单中消失。

使用已获准的资料归档流程，保留原始字节、原文件名、来源位置和内容哈希；同名异内容按工具规则保留版本，不覆盖。外部提供目录仍只读，未经授权不移动或删除。已获准管理的 `inbox/` 可按归档规则在复制校验成功后处理待接收原件；不能把这项授权扩展到外部原件。不要按章节复制同一文件，也不为分类修改原始 PDF、字幕或手写内容。

在课程记录 `<课程记录根>/materials.json` 中保留稳定材料ID、规范路径、原始来源、哈希、主分类、多用途标签、版本/学年、章节/课次与页码/题号/时间戳定位。工具管理的字段和文件格式遵循[课程文件入口](../../study-planner/references/course-files.md)。`materials-index.md` 提供从同一清单派生的可点击类型/章节索引，`materials.md` 保留实际用途和阅读范围：例如“一册讲义 → 第1章 PDF pp.3–12、第2章 pp.13–25”，“L03 字幕 → 00:12:20–00:18:05”。没有核对到的位置写待核对，不能猜页码或编造对齐关系。

同册题目与答案标两种用途；真题与评分说明按年份和题号关联。封面年份、适用学年、文件名年份可能不同，分别记录。每份文件说明实际检查位置、可读性、重叠/冲突和待确认项。文件是否存在、内容是否已读、相关分析是否需更新分别记录，不能把“可找到”当作“已核验”。

## 新文件对既有分析的影响

接收后报告：哪些已归档、哪些是副本、哪些待分类/不可读，以及本次涉及哪些章节与产出；给出新增入口和资料索引的实际路径。尚未完整读取就说明读取范围，不能只报“已同步”。

新增资料只补充其相关条目；内容改动或来源缺失时，将引用该来源的分析/笔记标为需复核，回读对应内容后更新。与变化无关的分析继续沿用。单纯移动且内容哈希一致时更新位置，不重做全部分析。不删除旧课堂、答案、作答证据或计划历史，也不把新资料倒写成学生过去已学会的内容。更正保留原因和旧来源对应关系；已交付笔记是否需刷新由实际引用范围决定。

## 主线、重叠与冲突

优先使用内容确认后适合本门课的主线资料。没有完整主线时从可读资料组合路线，说明依据与缺口。已有路线不是不可变脚本。

同一节的完整稿、分卷、手写、字幕、不同年份版本可能重叠，不能按文件数量重复教授。通过章节和实际内容确定关系；仅名称相近时记“可能重叠，待比对”。版本日期或教师口述与讲义有矛盾时保留双方证据，不默默选一个。

发现公式/答案冲突或原页不可读时，按[材料疑点与读取能力](source-checks.md)核对原意、复算及证据边界；未确认疑点不能记成已确认缺陷。影响当前结论且尚不能解决时限定该部分，其余可确认内容继续。

## 检查范围必须诚实

区分仅登记、内容抽样、相关段落已读、相关页面已视觉核对、待核对，并给出具体页/章节；“抽取了全文”只说明文本处理范围。建立整个课程的粗路线，当前课保留更细的覆盖与例题位置。预处理全课资料不应成为开讲前的长时间门槛。
