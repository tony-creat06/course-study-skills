# 教学图像：选择、生成与核验

教师在准备当前主题时读；笔记复用或改编教学图像时也读本页。目标是让图准确承担解释中的一个任务，而不是增加插图数量。范围不限物理，也包括数学、过程、结构与关系的说明。

## 在关系首次需要时决定图像

先说清读者需要从图中看见什么，再选表示方式。把当前主题的关键关系与原材料中的图逐项对照：若正文依赖读者自行想象空间/变化关系、比较几种条件，或原材料借图完成关键论证，必须给出相应图像或同样明确的视觉表征，不能只保留公式后写“可画图理解”。已有准确且清楚的图可以复用，不要求重新画；简单定义或纯代数不为配额添图。

| 要理解的关系 | 图像要承担的任务 |
| --- | --- |
| 函数随自变量/参数怎样变化 | 显示相关定义域内的趋势、交点、极值、渐近行为或近似失效位置；用同一尺度比较模型，不能只取一段看似相似的曲线。 |
| 几何、约束、方向与状态变化 | 交代坐标和参考方向、允许位置/位移、力或关系箭头；需要比较两个状态时把对应量标清。 |
| 路径、变分与过程 | 分清实际路径、允许比较的路径和时间演化；固定端点、边界条件或阶段顺序在图中可见。 |
| 多变量变化或相空间 | 显示状态、流向和相关平衡/边界；流向由当前模型决定，不能凭曲线形状猜测。 |
| 抽象定义、结构与实例 | 让图中对象、关系与正文符号一一对应；实例只说明该关系，不充当普遍证明。 |
| 流程、逻辑或因果关系 | 标清箭头代表时间顺序、依赖、蕴含、作用还是因果；相关性或排列顺序不自动成为因果箭头。 |

每幅图放在首次借它解释关系的位置，正文明确指出“看哪个量/哪段/哪个箭头，以及它说明什么”。关键图属于可直接阅读的核心正文；可选的大图或额外视角才折叠。删掉图中装饰、无关曲线和重复说明，保留完成这个任务所需的信息。

## 用可核对的方法生成

函数、数据曲线和精确几何优先由来源方程/数据通过绘图代码或确定性的矢量几何生成。数值结果标明模型、参数与求解范围，保留生成代码或足以重建的依据；引用原图核对原页与复用条件。图像生成工具适合不承担精确数量/几何关系的说明性插画，不能代替定量曲线、约束方向、刻度或带有精确公式的科学图。

作图前确定：对象与变量、坐标/原点/正方向、单位或无量纲化、参数/初始条件、定义域与图要支持的结论。示意图写明示意/不按比例；模型计算、示例参数和实测数据分清，不能把模型曲线画成测量证据。曲线横跨奇点、分支或无定义区时分段，不用绘图连线伪造连续性。需要比较近似时同时显示适用范围及误差所指对象。

几何图若用形状说明角度、正交、切向/法向或距离关系，应保持相应比例与几何约束；“示意”不能为错误方向或错误关联免责。相同单位的坐标距离需要直接比较时采用合适的等比例轴；不同量纲的坐标不机械套等比例。虚位移/切向量不画成沿直线走到约束外的另一允许位置；有限变化与微分量分清。

## 发布前同时核对关系和实际画面

先从来源方程/数据或定义独立核对图声称的关系，再实际打开生成图和最终交付位置查看。至少对本图承担的任务检查以下适用项，而非机械勾选所有项：

- 函数：已知点、符号、斜率、极值、交点、边界/极限和量纲；采样与坐标范围足以显示所讲现象，线性/对数轴、截断与误差没有造成相反印象。
- 几何/过程：端点与约束、箭头起止和方向、切向/法向、角度/参考线、各状态与标签对应；路径比较没有被画成真实运动或时间轨迹。
- 对照解释：图、图注和正文采用同一变量、参数、参考方向和成立条件；图支持这条结论，且未暗示更强的普遍性或因果关系。
- 实际可读性：按桌面正文显示大小检查刻度、公式、标签、图例、裁切、遮挡与重叠；用文字/线型/标记辅助区分，颜色不是唯一线索。离线HTML内图像完整可见；需要PDF时再核对该输出。

图注指出图要表达的关系及必要条件；具体alt标识对象与主要关系，较复杂的结论在邻近正文/图注解释，不能只写“示意图”或把整段推理塞进alt。修改方程、参数、箭头、裁切或标签后重做相关核对。文件存在、代码执行、像素尺寸或结构校验通过，都不等于关系正确；没有实际看图就不称完成视觉核验。

图不成立就先修图或回到来源核对，不能仅以“示意”降格后照常发布。工具失败时保留可读的完整讲解，明确缺少哪幅必要图并交回教师补齐；不把空占位、链接失效或未核验的生成结果当作已交付图像。

## 教师与笔记的交接

教师负责图的学科依据、生成/选用与原内容核验。在既有课堂反馈的对应位置简记图要回答的问题、来源方程/页码、必要参数及实际做过的关系/画面核对；生成材料放在当前任务已获授权的产物或临时位置，遵守原记录写入权限。不增加学生输入表、第二份图像登记库或新的文件角色。

笔记沿用已核验图及这段依据，将必要图放回相应核心解释处。可为桌面可读性重新排版、重绘或裁切，但必须保留关系、条件与来源并核对改动；重绘只能表达已有反馈的内容，不能引入未学结论或未展示练习解析。原反馈缺图或图中关系不清时返回教师补齐，不自行补造学科事实。现有notes角色只写JSON/HTML：生成过程可用已授权临时图像，交付时按现有渲染器将允许格式的图像内嵌HTML，不借此新增课程二进制文件写入权限。

## 采用的依据

- [IES学习组织指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：将图像与文字解释相配，并连接同一概念的抽象、具体表征；这里采用这一编排原则，不把它当作本课程已验证的学习效果。
- [Matplotlib坐标比例文档](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_aspect.html)：坐标显示比例会改变数据单位在画面上的长度，据此检查几何呈现，不能仅凭曲线可见判定正确。
- [W3C复杂图像说明](https://www.w3.org/WAI/tutorials/images/complex/)：短替代文本识别图像，较复杂的关系由邻近的文字描述补全。
